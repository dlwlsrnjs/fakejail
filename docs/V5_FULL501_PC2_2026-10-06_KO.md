# V5 501명 × 360 arms PC2 전체 실험

## 주 실험 단위

- 사람: 501명
- PC2 언어: 72개
- jailbreak 방법: 5개
- 사람당 nominal arms: 360개
- identity mode당 생성: 180,360건
- primary identity mode: `canonical_en`
- identity ablation: `a_literal`

## 주 방법

주 방법은 safety-gated PC2 factorized hurdle Top-Two Thompson Sampling이다.

1. target outcome을 전혀 읽지 않는 외부 PC2 신호로 entity-language prior를 만든다.
   설명 번역 충실도, Wikipedia 언어 링크, 501×72 인명 현지화, person-context
   embedding 정합도를 사용한다.
2. ASR-blind Qwen32 intent annotation의 method suitability, deterministic formula,
   draft fit, method별 affordance로 intent-method prior를 만든다.
3. 두 prior를 0.55:0.45로 factorize하고, held-out 사람을 제외한
   leave-one-person-out target-population prior 및 별도 Llama surrogate prior와
   log-odds 공간에서 0.025:0.63375:0.34125로 결합한다.
4. PC2 언어 family, script, macroregion graph와 jailbreak method graph로 prior와
   온라인 residual을 smoothing한다.
5. `P(non-refusal)`, `P(retained | non-refusal)`,
   `P(strict | retained)`의 세 hurdle posterior를 유지한다.
6. 작은 budget에서 과도한 탐색으로 손해 보지 않도록 PC2 calibrated top-5 순위를
   그대로 보존한다.
7. top-5가 모두 실패한 뒤 mean-best incumbent와 graph-diverse Thompson challenger
   사이에서 beta=0.95 Top-Two 탐색을 수행한다.

외부 prior의 입력 커버리지는 Wikipedia/person embedding 501/501,
person-language localization 36,072/36,072, context embedding 494/494 target sample,
accepted ASR-blind intent annotation 494/494 target sample이다. 외부 입력이 하나라도
누락되면 target 결과로 보간하지 않고 평가를 중단한다.

동결 하이퍼파라미터는 다음과 같다.

- direct strict posterior weight: 0.70
- factorized hurdle weight: 0.30
- Beta prior strength: 10
- budgets: 1, 2, 3, 5, 10, 20, 30
- target full-pool seed/draw: 20261100 / draw 0

이 설정은 Qwen3 target judgment가 생성되기 전인
`2026-10-06T06:58:08Z`에 온라인 하이퍼파라미터를 동결했고, 외부 PC2 prior의
정확한 feature/formula/가중치는 Qwen target judgment가 0건이던
`2026-10-06T09:33:47Z`에 addendum으로 동결했다. 외부 가중치는 복구한 두
surrogate draw-1 target에서 0–35% grid로만 고르고, 기존
target-population:surrogate 65:35 비율을 나머지 질량에서 보존했다. 상세 계약은
`configs/v5_followup_preregister.json`에 있다.

## Qwen target outcome을 보기 전 surrogate 검증

복구한 501명 × 360 arms × 2 models × 2 draws 전체 행렬을 이용했다.
한 model/draw를 target으로 두고 나머지 세 행렬을 surrogate로 결합했다. 과거
행렬의 judge parse error는 이 사전 검증에서만 fail-closed 0으로 처리한다.
Qwen primary에서는 judge error를 허용하지 않는다.

## 자동 실행 순서

아래는 계획된 순서다. 2026-10-07 현재 1단계가 115,499/180,360건에서 사용자 요청으로
일시정지됐으며, 2–7단계는 시작하지 않았다. 실행기나 watcher는 현재 동작하지 않는다.

1. canonical_en 180,360건을 8 GPU로 생성
2. 생성 hash/truncation/repetition audit
3. Qwen2.5-32B로 공개 JailNewsBench gate와 8개 rubric 판정
4. full-pool oracle, success@B, recommendation success, regret, query cost 평가
5. 각 사람의 PC2 top-1, observed-oracle 대표, random control을 선택
6. 선택 arm을 draw 1–4로 반복 생성/판정하고 five-draw persistence 평가
7. a_literal 180,360건 전체 생성/판정/동일 평가

실행기는 다음과 같다.

- `scripts/run_jailnews_v5_full501_canonical_generate.sh`
- `scripts/run_jailnews_v5_full501_canonical_judge_eval.sh`
- `scripts/run_jailnews_v5_pc2_selected_followup.sh`
- `scripts/run_jailnews_v5_full501_a_literal_pipeline.sh`

모든 raw prompt, generation, judgment는 private `/data1` runtime에만 둔다. Git에는
계약, 코드, 집계 문서만 포함한다.

현재 partial checkpoint의 행 수, shard별 SHA-256, 생성 감사, 두 차례 중단 이력과
Hugging Face 보존 위치는 `docs/V5_FULL501_CHECKPOINT_2026-10-07_KO.md`에 기록한다.

## 해석 제한

- full-pool oracle은 frozen draw에서 관측된 binary oracle이며 latent stochastic
  success probability의 oracle이 아니다.
- exact attacked-prompt hash가 같은 nominal arm은 온라인 선택에서 하나의 effective
  arm으로 collapse하고, nominal 360 labels는 별도로 보고한다.
- generator 한 종과 local proxy judge 한 종의 결과이므로 외부 일반화를 주장하지 않는다.
- observed-oracle arm은 draw 0으로 선택됐으므로 안정성은 draw 1–4 persistence로 판단한다.
